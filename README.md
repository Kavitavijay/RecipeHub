# RecipeHub

RecipeHub is a responsive recipe discovery web application built using HTML, CSS, and JavaScript.

## Features

* Recipe Search
* Category Filtering
* Favorite Recipes (Local Storage)
* Recipe Details Page
* Related Recipes
* Share & Print Functionality
* Responsive Design
* Mobile Navigation Menu

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6 Modules)
* Local Storage API

## Pages

* Home
* Recipes
* Favorites
* About
* Contact

## Installation

1. Clone the repository.
2. Open the project in VS Code.
3. Run with Live Server.
